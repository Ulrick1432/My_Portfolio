# This is my portfolio webiste :D 

## To run the application:
1. ### NodeJS is needed
2. ### Run with tailwind updates on, write "npm run build" in the terminal

## Explanation of some of the files
- tailwind.config.js
  - Is used to setup tailwind and set custom colors
- CNAME 
  - Used in connection with this project being hosted via GitHub Pages
  - GitHub Pages needs it to be able to associate a custom domain.
  - The file can be deleted if a custom domain is no longer needed or if it is no longer to be hosted at GitHub Pages
- /src/output.css
  - The file is part of the tailwind setup.
  - The file contains all tailwind classes, which can be modified.
- /src/input.css
  - The file is part of the tailwind setup.
  - The file contains custom tailwind classes, these classes contain other tailwind classes. This is to be able to have dynamic tailwind classes that match multiple identical HTML elements.
- /src/icons.css
  - The file is used to add logos to the various skills in the skills section (index.hmtl)
- /src/eventListener.js
  - The file is used for eventListeners.
- /resources
  - The folder is used to contain, images, etc.
